## Quick reply CRUD

1. User login menggunakan API dan cookie auth terpasang.
2. User membuka halaman `/quick-reply`.
3. User melihat list quick reply berhasil ter-load (judul halaman, tombol tambah, dan tabel terlihat).
4. User klik `Tambah quick reply`.
5. User mengisi `Perintah / Command` dengan command unik.
6. User memilih satu template pada modal `Pilih template regular`.
7. User klik `Simpan`.
8. User melihat toast `Quick reply berhasil disimpan` dan data baru muncul di tabel.
9. User membuka aksi pada row quick reply yang baru dibuat, lalu pilih `Edit`.
10. User mengubah command quick reply.
11. User klik `Simpan`.
12. User melihat toast `Quick reply berhasil disimpan` dan command hasil edit muncul di tabel.
13. User membuka aksi pada row quick reply hasil edit, lalu pilih `Delete`.
14. User konfirmasi hapus pada modal `Hapus template quick reply?`.
15. User melihat toast `Quick reply berhasil dihapus` dan data quick reply sudah tidak ada di tabel.
